# 전자교재 판서 엔진

전자교재용 독립 판서 엔진 개발 저장소입니다.

## 개발 원칙

- 기존 기능과 디자인 유지, 신규 기능보다 조작 편의성과 안정성 우선.
- 결함 재현 → 수정 → 회귀 시험 → 커밋 → 원격 확인.
- 검증된 항목과 미검증 항목 구분. 실제 와콤 및 운영 환경 검증 전 운영 배포 금지.
- v28 도구 접근성, v29 전체 배경 출력 및 데이터 복구, v30 종합 적대적 검증.
- WordPress·NAS 연동 및 GitHub Pages 배포는 보류한다. GitHub는 소스 버전 관리용으로만 사용한다.

## 등록 상태
