한 번 설치하고, 모든 지원 교재에서 판서

ZIP 저장이나 압축 해제 없이 브라우저에 설치합니다. 기존 교재 HTML은 변경하지 않습니다.

① 사용자 스크립트 관리자 설치 (최초 1회)

Chrome 웹 스토어에서 Tampermonkey 설치

이미 설치되어 있다면 건너뜁니다. Chrome 138 이상에서는 확장 프로그램의 세부정보에서 ‘사용자 스크립트 허용’을 켭니다. 이전 버전은 개발자 모드가 필요할 수 있습니다. 주소창에 chrome://extensions를 입력하면 설정할 수 있습니다.

② 판서 엔진 설치

판서 엔진 v35 설치 / 설치 확인 화면 열기

관리자의 설치 확인 화면에서 스크립트 이름과 권한을 확인한 뒤 설치합니다. 파일이 다운로드되거나 코드만 표시되면 관리자가 활성화되어 있는지 확인하고, 관리자의 ‘URL에서 설치’에 이 버튼의 링크 주소를 입력하세요.

현재 실행 범위: https://yuul-jung.github.io/* (상위 문서만). 외부 교재 파일이나 서버로 판서 데이터를 전송하지 않습니다. 엔진 버전은 v35.0.0으로 고정합니다.

③ 실제 교재에서 사용

AI 에이전트 교재 열기

Alt + Shift + Y : 판서 켜기/끄기. 단축키가 OS와 충돌하면 Tampermonkey 메뉴의 ‘판서 켜기/끄기’를 사용하세요. 기존 v34 확장과는 동시에 사용하지 않는 것을 권장합니다.

판서 데이터는 기존 브라우저 저장소에 보관하며 JSON 백업을 권장합니다. NAS, iframe, 실제 관리자 설치 및 와콤은 아직 미검증입니다.
