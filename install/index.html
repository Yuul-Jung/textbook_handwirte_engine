전자교재 판서 엔진 · v40

설치 없이 판서하기

확장 프로그램, ZIP, 권한 설정 없이 즐겨찾기 버튼으로 사용합니다.

① Ctrl + Shift + B로 즐겨찾기 바 표시

② 아래 버튼을 즐겨찾기 바로 드래그 (최초 한 번)

✎ 판서

버튼을 이 페이지에서 그냥 클릭하면 현재 화면에서 즉시 시험할 수 있습니다.

③ 교재에서 즐겨찾기 ‘판서’ 클릭

AI 에이전트 학습 안내서 열기

판서가 시작되면 오른쪽 끝의 10px 띠에 마우스를 가져가거나 클릭하여 도구함을 펼칩니다. 본문으로 이동하면 자동으로 숨겨집니다. 기본 8색, 사용자 지정 색상, 불투명도 10~100%, 굵기 1·2·3·4·6·8px, 색상과 불투명도를 도구함 상단에서 바로 선택할 수 있습니다. 교재의 글자색과 분리한 고대비 도구함을 적용합니다. F8 또는 즐겨찾기 버튼으로 판서 자체를 켜고 끕니다. 새 페이지로 이동하거나 새로고침한 경우에는 즐겨찾기 버튼을 다시 클릭합니다.

새 버전은 같은 즐겨찾기 주소에서 다음 실행 시 가져옵니다. 이미 실행 중인 페이지는 새로고침 후 다시 클릭합니다.

필기 시험 공간

위의 ‘판서’ 버튼을 클릭한 후 여기에 필기하세요. 오른쪽 끝의 얇은 띠를 클릭하거나 마우스를 가져가면 도구함이 펼쳐집니다.

사용 범위

HTTPS 및 호환되는 교재 구조에서 사용합니다. NAS의 HTTP, 사이트 CSP 정책, 실제 와콤 및 즐겨찾기 바 드래그는 추가 검증 대상입니다. 이전 Tampermonkey 판서 스크립트가 켜져 있으면 중복 실행을 방지하기 위해 비활성화하세요. 기존 웹사이트 소스는 수정하지 않으며, 판서는 브라우저 저장소에 보관됩니다.
