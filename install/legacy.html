자동 업데이트

Tampermonkey 설정에서 스크립트 업데이트 확인과 자동 설치를 활성화하세요. 새 버전은 동일한 설치 주소에서 제공되며, 기존 교재 파일과 저장 데이터는 변경하지 않습니다. 설치 후 열려 있던 교재 탭은 새로고침하세요. 자동 설치가 꺼져 있으면 관리자의 업데이트 승인 또는 위 버튼을 사용하세요.

v35에서 전환할 때도 기존 스크립트 식별자를 유지합니다. 기존 ZIP 확장 프로그램(v34)은 중복 실행 방지를 위해 비활성화하세요.
